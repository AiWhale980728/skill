# Editorial workflow

## Material map

Record each input as M01, M02, and so on with: modality, original path or URL, source type, date, central information, fact/opinion/example/data/method classification, verification state, visual cues, risks, and intended use. Link evidence across modalities instead of summarizing each item in isolation.

For long documents, map the structure first and read closely only where it supports viable angles. For screenshots, capture visible text, interface state, version and time clues, while removing personal data, credentials, and internal information.

## Content signals and selection

Extract 3–7 signals. For each, state its audience value, supporting evidence, story potential, missing information, and difference from common coverage.

Assess candidates from 0–5 on:

- audience value
- novelty or timeliness
- credibility
- story potential
- visual potential
- platform fit
- differentiation
- safety

Use scores as decision support, not an automatic winner. Explain decisive tradeoffs.

## Research

Research claims at claim level. Prefer official documentation, standards, papers, original datasets, company announcements, official repositories, release notes, and licenses. Add reliable secondary sources only for context or corroboration. Record retrieval date, scope, methodology, and uncertainty.

For lists and rankings, disclose snapshot date, population, filters, ranking method, and exclusions. Do not infer an algorithm from page order.

## Story patterns

- Explanation: familiar problem → plain-language definition → mechanism → example → boundary.
- Comparison: shared decision → meaningful differences → fit by user → tradeoff → choice.
- Process: starting state → key steps → observable result → failure point or cost.
- Commentary: evidence → interpretation → counterpoint → implication → actionable conclusion.
- Collection: selection rule → each item's distinct value → boundary → decision guide.

For every page or shot, write: purpose, audience takeaway, scene, action, exact text, source, and boundary.
